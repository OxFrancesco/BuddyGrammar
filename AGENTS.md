## Reference codebases (codeview)

The `resources/` folder contains read-only clones of reference codebases.
If you need to implement code specific to one of these codebases, read the relevant
folder to gather information, feedback, patterns, and templates before writing code.

- `resources/openrouter-examples` — Official OpenRouter integration examples and request patterns
- `resources/mlx-swift-lm` — Official MLX Swift language-model generation APIs used by BuddyGrammar
- `resources/megaphone` — Megaphone macOS dictation reference — Apple SpeechAnalyzer streaming, model assets, vocabulary context, and low-latency transcription
- `resources/aosp-latinime` — AOSP LatinIME reference for pointer tracking, key detection, layout state, editor integration, and compatibility
- `resources/heliboard` — HeliBoard reference for offline keyboard architecture, declarative layouts, language assets, gestures, and personalization
- `resources/futo-keyboard` — FUTO Keyboard source mirror for modern Android IME models, gesture typing, editor compatibility, and performance fallbacks
